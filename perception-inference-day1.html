DAY 1 · PHASE A 认知

感知即推断

预测加工 · 贝叶斯大脑 · 主动推理

2026-07-10 · BigCat

你以为你在"看见"世界——其实你在"猜"，世界只负责纠错。

// 为什么从这里开始

整个神经科学，我们不从神经元、不从离子通道开始，而从你此刻正在做的事开始：感知。因为一个反直觉的转向，会重排你对大脑的整个直觉——大脑不是被动接收信息的相机，而是主动生成假设、再用感官数据纠错的预测机器。你看到的每一帧，都是大脑的"最佳猜测"。这一期只讲一件事，但讲透它，后面的注意、记忆、意识都会顺下来。碰到需要底层构件的地方，我给 参考页 的链接，不在这里补地基。

// 01

大脑是预测机器，不是接收器

论断：感知的主流方向不是"感官 → 大脑"，而是"大脑 → 感官"——你先有预测，感官只送回差错。

老直觉是自下而上：光子打到视网膜 → 信号层层上传 → 大脑"看到"。但解剖学早就打脸了这个方向——在视觉通路里，从高层皮层"下传"到低层的连接，数量远超从感官"上传"的。大脑主要在忙着往下发预测，而不是往上收数据。

证据就在你眼皮底下：错觉。同样的灰色方块，放在不同背景上你会看成不同深浅；一旦你"知道"某张模糊图是什么，就再也"看不回"没意义的斑点。这些都不是眼睛的 bug，而是先验（大脑的假设）压过了感官输入——证明你看到的从来不是原始像素，是被预测塑形过的结果。

感官数据的第一站怎么被组织、"下传预测"具体投射到哪，属于底层通路的活儿：视觉通路

AI 对读

这正是生成模型的世界观：与其存一堆像素，不如学一个能"生成"世界的内部模型，再让它去解释输入。判别式模型问"这是什么"，生成式模型问"什么样的世界会产生这个输入"——后者才是大脑的默认姿态。你训练一个 VAE / diffusion 时的那个"先验 → 生成 → 比对"回路，和皮层"预测 → 下传 → 纠错"是同一个骨架。

// 02

只有"没猜中的"才值得上传：预测误差

论断：大脑分层地预测自己，每一层只把"预测误差"传给上一层——省带宽，也解释了为什么熟悉=无感。

分层预测编码是这套机制的引擎。想象皮层是一叠层：每一层都试图预测下一层的活动，把预测下传；下层拿预测和实际输入一比，只把对不上的部分（误差）上传。猜对的信息根本不往上走——因为它不带新消息。

这一下解释了一堆日常现象：你听不见自己家的空调声（完全可预测 → 零误差 → 不上传），但它一停你立刻警觉（预测落空 → 大误差）。越熟悉的东西越"隐形"，不是感官变钝，是它们已经被预测吃掉了。大脑的注意力，本质是留给意外的。

高层皮层 ── 预测 ↓ ──▶ 低层皮层 ── 预测 ↓ ──▶ 感官 ▲ ▲ └──── 误差 ↑ ──────────┴──── 误差 ↑ ──── （只有"没预测到的"往上走） 猜中 = 静默（不占带宽） 猜错 = 上传（更新模型）

AI 对读

"只传残差"你太熟了——残差连接 / 预测编码压缩都是这个思想：不重复已知，只编码增量。更妙的对读是自回归模型的训练信号：LLM 每一步都在预测下一个 token，损失（cross-entropy）就是"预测误差"，梯度只沿着没预测准的方向更新权重。大脑用误差实时调后验，模型用误差离线调参数——同一种"被惊讶驱动的学习"。

// 03

贝叶斯大脑：你看到的是先验 × 证据的后验

论断：感知是一次贝叶斯推断——先验越强/证据越弱，你就越"看见你以为的"，而不是"在那儿的"。

把上面两点写成一个公式的直觉：感知 ∝ 先验 × 似然。先验 = 大脑基于经验的预期，似然 = 当前感官证据。你最终"看到"的，是两者加权后的后验。

关键在加权：谁的话更算数，取决于精度（可信度）。光线昏暗时感官证据不可靠（似然精度低），先验就接管——于是你把衣架看成人影、把风声听成人声。反过来，光天化日下证据充分，先验让位。这也给了"注意"一个精确定义：注意 = 调高某处感官误差的精度，让它更有权更新你的世界模型。（注意本身是 Day 2。）

AI 对读

这是不确定性加权的推断：贝叶斯神经网络、Kalman 滤波、乃至扩散模型里的 guidance scale，本质都在做"证据不足时更信先验"。工程师手动调的那个"先验强度 / temperature"，大脑用精度自动、逐感官地在调——而且是实时的。幻觉（hallucination）在两边是同一个故事：先验被过度采信、证据被压过，模型/大脑就"看见"了不在那儿的东西。

// 04

主动推理：感知与行动是同一枚硬币

论断：减少预测误差有两条路——改模型（感知），或改世界（行动）。大脑两条都用，于是感知和行动本就一体。

预测误差怎么消？前三节讲的是更新大脑（改后验去贴合世界）。但还有一条对称的路：改世界去贴合预测——这就是主动推理。你预测"眼睛应该看到桌子的中央"，于是你动眼睛让它真的看到中央；误差被抹平，不是靠改信念，是靠行动。

推到底，这给了运动一个惊人的重述：动作，就是被身体实现的预测。你伸手拿杯子，是大脑预测"手已经在杯子上了"，这个预测的误差驱动肌肉去实现它。感知问"世界是什么样"，行动问"我怎么让世界变成我预测的样"——同一个误差最小化引擎，两个出口。这也是为什么后面讲运动、决策、乃至冥想（主动调节自己的预测），都能挂回这一根主线。

AI 对读

主动推理是 RL 的一个耐人寻味的替身：RL 最大化外部奖励，主动推理最小化预测误差（自由能）——很多时候两者等价，但后者把"探索"和"目标"统一进了同一个量。它天然是基于世界模型的智能体（world-model + planning，像 Dreamer 那一系）：先有内部模型、用它想象、再行动去让想象成真。当下 agent 研究在重新发现的东西，大脑用了几亿年。

// 深入思考

如果我"看到"的永远是大脑的猜测，那我凭什么相信我看到的世界是真的？
严格说你从来没有"直接"接触过世界——你接触的一直是大脑的模型。但这不导致怀疑论：这个模型被持续的预测误差拴在现实上，猜错就要付代价（撞墙、抓空）。所以感知不是幻觉，是一个被现实不断校准的受控幻觉——够真到让你活下来，但永远不是"像素级的真相"。这也解释了为什么两个人可以"看到"不同的东西：先验不同，后验就不同。
预测加工说"熟悉=零误差=无感"，那为什么我们还会享受重复（重听一首歌、重看一部电影）？
因为"误差"不是只有一层。低层（音符、画面）被预测掉了，但高层（情绪结构、意义、与记忆的共振）仍在产生新误差；而且完全可预测本身可以变成一种低误差的安全感（这正是仪式、ASMR、白噪音起效的机制）。审美的甜区往往在"可预测的骨架 + 恰到好处的意外"之间——太意外是噪声，太可预测是无聊。这一点在 Day 19 敬畏、以及音乐认知里会再回来。
既然大脑和生成模型是同一个骨架，那 LLM 的"幻觉"和人的"错觉/妄想"是同一回事吗？
机制层面高度同源：先验（模型内部）被过度采信、外部证据被压过，两者都会"生成"不存在的细节。但有一个关键不同——健康大脑有主动推理这条腿：它能去行动、去采样新证据来证伪自己的猜测（多看一眼、伸手摸一下）。当前 LLM 大多没有这条"主动去查"的闭环，只能在已有先验里往下生成——这也提示了缓解幻觉的方向：给它取证据、并让证据有权压过先验的能力（工具调用/检索本质就是给模型接上"感官"）。
