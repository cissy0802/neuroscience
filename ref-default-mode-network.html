默认模式网络Default Mode Network

一组你什么正事都不干、放空走神时反而最忙的脑区。它管的几乎全是"关于我"的事——回忆过去、想象未来、揣摩别人——所以又常被叫作大脑的"我"网络、那台放"我的故事"的放映机。

它是"任务负相关"的：你越闲，它越亮

大多数脑网络是"你派它活它才动"。默认模式网络反过来：你一专心做外部任务（算题、盯路），它就安静下来；你一放空、发呆、任思绪乱飘，它反而全体点亮。当年就是有人注意到，扫描时被试"什么都不做"的那些空档里，总有同一批区域稳定地更活跃——它不是噪声，是大脑的"默认档"。

内侧前额叶（mPFC）
处理"关于我"的信息：我的偏好、我的性格、这事对我的价值。自我参照加工的主力。
后扣带皮层 / 楔前叶（PCC / precuneus）
整个网络的枢纽，代谢极高。串联自传体记忆与自我视角；它的活动强弱几乎是"你有多沉在自我叙事里"的一个刻度。
角回 / 颞顶联合区（TPJ）
心智理论与视角采择——"别人会怎么想""从我的位置看出去"。
海马结构
把过去的情景调出来、也用同一套零件拼出未来的想象——记忆与"未来预演"共用这套硬件。

它和"专注网络"像跷跷板

默认模式网络和管外部专注的背侧注意网络大体此消彼长：一个亮，另一个就暗。这解释了一个日常体验——你走神（DMN 上线）时，对眼前的路和别人说的话就变迟钝（注意网络下线）；反过来深度专注时，那个喋喋不休的"内心独白"会短暂消失。所谓心流，一部分就是自我叙事这台放映机被任务盖过、暂时调暗了。

为什么它对"自我""冥想""临床"都关键

因为它几乎就是自我叙事的神经底座，调制它就能调制"我"：

自我与自我消解
深度冥想与裸盖菇碱等迷幻物质都会下调 / 打散这张网，报告的"无我""万物一体"强度与其活动下降近乎成正比——这是"自我是被算出来的"最直接的一条证据（主线 Topic 17）。
抑郁与反刍
抑郁常伴 DMN 过度活跃 / 过度连接：停不下来的"反刍"——反复咀嚼"我怎么这么糟"——正是这台放映机卡在负面自我叙事上转不出来。
阿尔茨海默
AD 早期的病理与萎缩，高度重叠于默认模式网络的核心区（尤其后扣带/楔前叶）——这也是它代谢高、最"费"、最先出问题的一个线索。
